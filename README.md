# hxyfront-62008 烟花编排变更单台

源提示词编号：10（在原烟花燃放脚本编排基础上改为变更单工作台）

面向烟花燃放编排师的变更单工具：预置三段节目、六个点火节点、四个燃放点位。改动已签批节点时先生成变更单，沿同一点位后续未执行节点逐项传播，经安全与音乐负责人对同一版本双签后才整体生成新签批版本。

## 业务规则

- 节点记录：点位、点火毫秒、持续毫秒、音乐拍点、签批版本、执行状态。
- 已签批节点被改动 → 生成变更单；同一点位后续**未执行**节点按增量逐项传播（已执行节点截断传播）。
- 硬性校验，任一触发则整张变更单退回、原脚本不动：
  - 新点火时间越过节目段落；
  - 与音乐拍点偏差超过 **80ms**；
  - 与同点位前发间隔短于 **1.2s**。
- 安全负责人、音乐负责人对**同一版本指纹**均确认后才能签批；内容任何修改都会刷新指纹，两人确认全部作废，需重签。
- 签批后生成新版本（v2、v3…），旧版本与快照全部留档；退回/签批记录可查。
- 时间轴、点位图、变更记录随草稿实时同步；数据写入 localStorage，浏览器重开后仍可查。

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `src/rules.ts` | 业务规则：模型与预置数据、变更单生成/传播、三条硬性校验、版本指纹、双签与版本生成（纯函数） |
| `src/store.ts` | 版本存储：localStorage 持久化、React 状态流转，业务判定全部委托 rules.ts |
| `src/App.tsx` | 页面交互：时间轴编排、点位平面图、变更单工作台、变更记录与版本留档 |
